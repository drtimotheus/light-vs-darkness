Light vs Darkness TCG — game app (Core Rules v6.1), installable web app (PWA)
Live at https://drtimotheus.github.io/light-vs-darkness/
Built from the local game app at commit 0f732ce (branch rulings-2026-11-20 on top of 4aef056: Timothy's S1-102 rulings of 2026-11-20, which say a Power of Agreement copy and a Transformed Mentor count for Barak; the R4 N1 fix; PWA manifest, icons, generated sw.js version e21797321631). The Rules button points to the -20b revised rulebook (with the Q1/Q2 sentence): https://inspiringyourfaith.org/wp-content/uploads/2026/11/Light-vs-Darkness-TCG-Core-Rules-v6.1-Rev-2026-11-20b.pdf. That address must return HTTP 200 before deploy (checked at deploy time).
1–4 players on one device against the Dark Deck. Sets 1, 2 and 3 are playable.
iPhone: open the link in Safari > Share > Add to Home Screen.  Android/Chrome: menu > Install app.
After the first load it works offline (card close-ups are cached as you view them).
Full rules: Light vs Darkness TCG Core Rules v6.1, free at https://inspiringyourfaith.org/tcg/
The old Version 5 game is kept on the branch legacy-v5 and the tag legacy-v5-final.
