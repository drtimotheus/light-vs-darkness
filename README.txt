Light vs Darkness TCG — game app (Core Rules v6.1), installable web app (PWA)
Live at https://drtimotheus.github.io/light-vs-darkness/
Built from the local game app at commit f7db667 with a small web-deploy patch (PWA manifest, icons, generated sw.js).
1–4 players on one device against the Dark Deck. Sets 1 and 2 are playable; Set 3 is coming in a future update.
iPhone: open the link in Safari > Share > Add to Home Screen.  Android/Chrome: menu > Install app.
After the first load it works offline (card close-ups are cached as you view them).
Full rules: Light vs Darkness TCG Core Rules v6.1, free at https://inspiringyourfaith.org/tcg/
The old Version 5 game is kept on the branch legacy-v5 and the tag legacy-v5-final.
