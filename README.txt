Light VS Darkness — installable web app (PWA)
Upload the CONTENTS of this folder to any static HTTPS host (GitHub Pages, Netlify, Cloudflare Pages, Vercel).
Works under a subpath (all URLs are relative). Version 0c01d18e09b8.
iPhone: open the link in Safari > Share > Add to Home Screen.  Android/Chrome: menu > Install app.
After the first load it works fully offline. To update: rebuild, upload, and the app picks up the new version next launch.
Rules: Version 5 (Draft 5) — full rulebook: LVD-Rulebook-v5.pdf
